**# Laboratorio Final: Casa con IoT

Este repositorio contiene la documentación, capturas de pantalla y el desarrollo del **Laboratorio Final de una Casa con IoT (Internet de las Cosas)**. 

A continuación, se presentan las evidencias fotográficas del funcionamiento del sistema, configuradas mediante etiquetas HTML para facilitar la personalización de su tamaño, alineación y disposición.

---

## 📸 Evidencias del Laboratorio

> **Guía de personalización:** > - **Tamaño:** Cambia el valor numérico en `width="..."` (por ejemplo, `width="400"` para hacerla más pequeña o `width="800"` para más grande). Puedes usar también porcentajes como `width="50%"`.
> - **Posición:** Por defecto están centradas con `<p align="center">`. Si prefieres alinearlas a la izquierda o derecha, cambia `center` por `left` o `right`.
